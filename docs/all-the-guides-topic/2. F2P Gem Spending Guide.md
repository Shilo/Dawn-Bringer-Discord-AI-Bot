# F2P Best Use of Gems Guide

## Priority Order

### 1. Daily Refresh (2 hours)
- Refresh every day
- First 3 refreshes are worth it
- 4th might be too pricey (requires VIP 2)
- 5th requires VIP 8

### 2. Collection to Level 5
- Collections unlock on Day 4
- Get Collection to level 5 as soon as possible

### 3. Diva to 2 Star
- Use valk tickets to get Diva to 2 star

### 4. Save 10-20k Gems
- Save for UR events or other special events
- Otherwise, keep spending in collections

### 5. Collections Investment
- Collections is absolutely the best gem:power ratio until VERY VERY late in the game
- This is where F2P should generally stop and save
- If you want to spend more gems, proceed to special events

### 6. Special Events
- Usually worth the gems
- Sprint events: spend gems up to EACH STEP worth of completion
  - If you spend gems, spend enough to complete the step, otherwise save

### 7. Freedom Arena Extra Tickets
- Worth it for mining resources you get

## Additional Notes

**Collections Investment:**
- Investing in collections above level 5 (unlocks day 4) will generally give you the largest power increase in this game
- Collection items are just THAT good as they rank up and you acquire more
- Costs 5,000 Gems per 10 collection pulls, so it is NOT cheap, especially for F2P players

**Valk Pulls:**
- Spending diamonds on valk pulls is not a waste
- However, those diamonds might be better put towards collections
- Use tickets (10 a day) for valk pulls instead
- This falls onto your own discretion
