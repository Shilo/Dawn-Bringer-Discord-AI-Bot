# Sprint Schedule

## Timing

Besides Stage and Valkyrie Power, the other Sprints have shared schedule on other servers. They start at daily reset, at 00:00 game time (12:00 AM) and end at 23:59 game time (11:59 PM). Keep in mind this is 60 seconds before the reset. Game time uses UTC -07:00.

## Projected Cycle

The game is expected to follow the cycle of (1) > (2) > (3) > (4) > (1) > ... for sprints, where:

1. **Titan** with **Valkyrie Recruitment**
2. **Tech** with **Divine Armament**
3. **Titan** with **Skill**
4. **Tech** with **Collection Appraisal**
