# Backpack Tech Tree Guide

There are two main schools of thought for building your tech tree: **Stun VS Damage**

---

## Damage Build

*This build is the most effective build for pure damage, and the one recommended personally.*

### Early Game
Split all tech crystals between all three attack nodes (one on each tree). This is the best way to build early on, till you have enough tech crystals to get your first point in the "global attack" node.

### Mid to Late Game
Once you have **1910 tech crystals total**, you can get your first point in "global attack node."

1. Respec all trees
2. Put as many points into the "global attack" node as you can
3. Extra points can be divided among the attack nodes of the other two trees

As you continue to get more tech crystals, keep respecing and boosting global attack when able, while putting remainder into the other two attack nodes.

### Paths to Global Attack

There are 6 main paths to Global Attack:

#### Guardian Tree
- **HP > Atk > Dodge/Stun > Global Atk**
  - Alternative Option for all classes
- **Def > Atk > Ignore Dodge/Skill Crit > Global Atk**
  - Likely, Best for Stun Blue
  - *Note: This node says "final damage" in description, but it is actually believed to be skill crit related*

#### Vanguard Tree
- **HP > Atk > Dodge/Pierce > Global Atk**
  - Best for Pierce Pink
- **Def > Atk > Ignore Dodge/Critical Hit > Global Atk**
  - Likely, Best for Crit Pink
  - *Note: This node says "skill crit" in description, but it is actually believed to be NORMAL crit, not skill crit related*

#### Cannon Tree
- **HP > Atk > Dodge/DR Chance > Global Atk**
  - Best for Red DR Team
- **Def > Atk > Ignore Dodge/DR Chance > Global Atk**
  - Not a great option

## Stun Build

*This build DRASTICALLY reduces your damage potential, but you basically get perma stun on most bosses (Yonai and Digital Simulation excluded).*

### Early Game
Split all tech crystals between all three attack nodes (one on each tree). This is the best way to build early on, till you have enough tech crystals to get your first point in the "Stun" node.

### Mid to Late Game
Once you have enough tech crystals to start building the stun node:

1. Put anywhere from **5-15 points** into the Stun node till you like the balance of your stuns vs knockbacks
2. After you have the stun node where you like it, follow the damage build above
3. **Recommended:** Use the Guardian HP path listed in the Damage Build section if aiming for the stun build
