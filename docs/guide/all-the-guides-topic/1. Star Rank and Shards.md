# Star Rank and Shards Guide

## Shards Required for Each Star Rank

**Zero → ⭐ (1 Star)**
- Per level: 4, 4, 4, 4, 4 = 20 shards
- Total: 30 shards

**⭐ → ⭐⭐ (2 Star)**
- Per level: 10, 10, 10, 10, 30 = 70 shards
- **Best value** - Every UR needs this to be viable late game
- Total: 100 shards

**⭐⭐ → ⭐⭐⭐ (3 Star)**
- Per level: 30, 30, 30, 30, 80 = 200 shards
- Total: 300 shards

**⭐⭐⭐ → ⭐⭐⭐⭐ (4 Star)**
- Per level: 80, 80, 80, 80, 200 = 520 shards
- Total: 820 shards

**⭐⭐⭐⭐ → ⭐⭐⭐⭐⭐ (5 Star)**
- Per level: 200, 200, 200, 200, 300 = 1,100 shards
- Total: 1,920 shards

**Total requirement for 5-stars: 1,920 shards**
