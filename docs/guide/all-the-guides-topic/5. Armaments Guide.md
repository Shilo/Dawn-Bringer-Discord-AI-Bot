# Armaments Guide

## Gacha Information

- **Cost:** 8k gems for 10 pulls
- Generally, collections is a more worthwhile investment
- **Rarities:** Green/Blue/Purple (purple being the strongest)
- **Gold armaments ARE possible** in the gacha (recently confirmed by community member)

## Armament System

- Armaments are divided into several categories
- Each category has two types of armaments (for instance, one might scale ATK, while the other scales HP)
- As you progress in the Divine Core Lab, you unlock more equip slots, so you can equip multiple armaments at once
- **Combining:** Requires Gold-Rarity of BOTH armaments per category to use
- You can level up each armament individually so when equipped they give better stat gains
