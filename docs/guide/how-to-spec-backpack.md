# How to Spec Backpack

This guide includes tech core breakpoints for optimizing your backpack specialization.

## Early Game (873 Tech Cores)

- **20 attack boost in each tree** until you can get to **1 global attack point** (873 tech cores)
- First branch chosen is the **2 o'clock/blue guardian node** for stun and global attack
  - Stun chance makes 5v5 content much more reliable to clear
  - 5v5 content includes: corridor, digital simulation, and PvP
- Finish branch to **10** (4008 tech cores)

## Mid Game Progression

### First Global Attack Branch (4008 Tech Cores)

- Work towards another global attack branch
- Second branch chosen is the **10 o'clock/orange vanguard node** for basic attack crit chance and global attack
  - Reasoning: While pierce damage may have higher potential damage output, having **80% basic attack crit chance** will provide far more reliable sustain DPS over the same period of time

### Double Branch Strategy (5533 Tech Cores)

- Change to **5/6 global attack double branch** (one branch 5 global attack, one branch 6 global attack)
- Level both of these back and forth evenly for tech core efficiency to both to **10** (8016 tech cores)

> **Note:** Anything past this point you won't have unless you either swiped or played a very long time

## Late Game Progression

### Third Global Attack Branch (8016 Tech Cores)

- Work towards third global attack branch
- Third branch chosen is the **2 o'clock/blue cannon branch** to continue getting HP and global attack
- Change to **7/7/7 global attack triple branch** (each branch at 7 global attack - 9381 tech cores)
- Level all three evenly for tech core efficiency to **10** (12024 tech cores)

### First Final Attack Branch (12024 Tech Cores)

- Change to **1 final attack full branch + 1 branch lv 10 global** (12733 tech cores)
- First final attack branch chosen is the **10 o'clock/orange guardian node** in order to get both skill crit chance and retain stun
  - This means you will reset your guardian tree to reallocate points
  - Same reasoning as basic attack crit chance: having **80% skill crit chance** will provide reliable sustain DPS over time while still retaining stun for 5v5 content

### Continued Progression

- **1 final, 3x lv10 global attack** (20749 tech cores)
- **2 final, 1x lv10 global attack** (21458 tech cores)
- Second final attack branch chosen is the **10 o'clock/orange vanguard node** in order to keep basic attack crit chance
- **2 final, 3x lv10 global attack** (29474 tech cores)
- **3 final, 1x lv10 global attack** (30183 tech cores)

### Advanced End Game (30183+ Tech Cores)

- All three **10 o'clock/orange branches** will be chosen to gain both global HP and global attack
- **3 final damage, 6x lv10 global attack, 3x lv10 global HP** (38199 tech cores)
- **3 final damage, 6x lv10 global attack, 3x lv10 global HP, 3x lv10 global defense** (49350 tech cores)

> **Note:** Anything past this point you will have to double down on a previous branch. Repeat same cycle starting from building towards next global attack point.
