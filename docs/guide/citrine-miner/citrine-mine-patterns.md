# Citrine Mine Repeating Patterns

## Overview

The Citrine Mine features repeating 7x6 grid patterns that appear every 7th row. These patterns become available after reaching 5k depth.

## Grid Changes (v0.0.25)

- The visible grid was reduced from 7x6 to 6x6
- Patterns remain the same (7x6)
- There is now an invisible row at the top which can be interacted with by drills
- Consumable lasers and bombs can hit 2 invisible rows (as tested)

## Pattern Information

The mine uses 12 different patterns, 2 of which are treasure patterns. Patterns can repeat back-to-back, including the same pattern consecutively.

## Suggested Paths

The suggested paths for these patterns are designed to:
- Maximize rewards and tiles cleared
- Minimize drills used

Note: Patterns may vary between accounts. You may need to identify your own patterns and optimize paths accordingly.
