## :rotating_light: [How to __Report Cheater__?](https://#)    [▲Top](https://discord.com/channels/1330797390185234513/1423687297454575716/1423687297454575716)
> 1. **Verify** the potential that the player has cheated.
> 2. Report the player's **UID**, **activity** and relevant cheater **screenshots**:
>   - **Customer Service** via `In-game > Settings > Customer Service`
>   - Email [rgsupport@topgamesinc.zendesk.com](mailto:rgsupport@topgamesinc.zendesk.com)
>   - Contact [support website](https://topgamesinc.zendesk.com/hc/en-us/requests/new)
>   - Post in [Cheater Report Log](https://discord.com/channels/1330797390185234513/1421030240632700938/1421030240632700938)
> 3. Use the cheater report **template** below. `(Copy / Paste)`
> 
> **Template:**
> ```
> ### Run Goddess Cheater Report
> - UID: <Cheater unique identification>
> - Name: <Cheater user name>
> - Reason: <Explain how they cheated>
> - Evidence:
> ```
> 
> **Example Report:**
> ```
> ### Run Goddess Cheater Report
> - UID: 12345
> - Name: Captain12345
> - Details: Likely using a modded app. Stage 300-15 with only 50m global power.
> - Evidence:
> ```
>
