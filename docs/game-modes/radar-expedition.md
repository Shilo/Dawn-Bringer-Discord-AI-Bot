# :satellite: Radar Mode

### Tips
- `Refresh` (re-roll) **lowest** :star: exploration **task** for **extra XP** (rewards are neglectable).
- `Complete Now` is **not useful** because global `Auto-refresh` time is fixed.
- `Quick Deploy` should be **100% rewards** if you've played long enough.
- `Tap Level icon` to see `Task Target Quality`. Only a range of **3 types of :star:** per level.

### Level 35 Total UR Elaris Rewards
- 135x **Elaris Shards**
- 11x **Eternal Night Radiance** (Elaris Ultimate Weapon)
