# Sprints Overview

## Basic Mechanics

Sprints are short timed events that provide rewards based on completed tasks and attained rank on the server. Rewards include general consumables, Sprint Gift Funds and Sprint Vouchers which can only be spent in the Sprint shop.

## Tasks and Ranks

Sprint Gift Funds are rewarded when all the tasks in a round are completed. There are 4 rounds in a Sprint and each time a round is completed, the tasks are reset to 0. Sprint Vouchers are rewarded as rank rewards after the Sprint ends.
